X(구 Twitter)는 과거에 두 가지 다크 테마를 제공했습니다.
・Lights Out(검정) — 순수한 검정 배경
・Dim(DarkBlue) — 차분한 짙은 파란색 배경

하지만 현재는 Dim(DarkBlue) 테마가 폐지되어 다크 테마는 검정 하나뿐입니다.

'돌아온 DarkBlue 테마(X)'는 X의 검정 다크 테마를 과거의 차분한 DarkBlue(Dim) 테마로 변환하는 확장 프로그램입니다.

■ 주요 기능
・X의 다크 테마(검정)를 예전 DarkBlue 테마로 자동 변환
・확장 프로그램 아이콘으로 여는 팝업의 스위치로 한 번에 ON/OFF 전환(기본값: ON)
・라이트 테마 사용자에게는 영향을 주지 않는 안전한 설계(라이트 테마에서는 변환하지 않습니다)
・페이지 안에서의 화면 전환이나 나중에 불러오는 내용에도 색상을 적용
・타임라인, 알림, DM, 검색, 설정 등은 물론 통화 화면과 채팅 화면(배경, 메뉴, 새 채팅 대화상자)에도 DarkBlue 색상을 적용
・확장 프로그램의 팝업에서 원하는 경우 문의를 보낼 수 있습니다

■ DarkBlue 색상 팔레트
기본 배경: #15202B
카드 배경: #192734
호버 배경: #22303C
테두리: #38444D
강조색: #1D9BF0

■ 사용 방법
1. X(x.com)에서 다크 테마(검정/Lights Out)로 설정하세요.
2. 확장 프로그램을 설치하면 DarkBlue 테마가 자동으로 적용됩니다(설치 또는 업데이트 후에는 X 페이지를 새로고침하세요).
3. 확장 프로그램 아이콘을 클릭하고 팝업의 스위치로 ON/OFF를 전환할 수 있습니다.

■ 문의 기능
팝업에서 '문의하기'를 누를 때만 Kagayoi Support(https://support.kagayoi.com)에 연결하는 데 필요한 권한의 허용을 요청합니다.
허용하지 않으면 문의 양식은 열리지 않지만, 테마 변환은 그대로 사용할 수 있습니다.

■ 개인정보 보호
・테마 변환은 브라우저 안에서 완결됩니다
・사용자가 선택 사항인 문의 양식을 제출할 때만, 입력한 이메일 주소, 선택 입력한 이름, 문의 내용, 확인 코드 등을 Kagayoi Support로 전송합니다
・문의 인증 후에는 이메일 주소, 액세스 토큰, 유효 기간을 양식의 페이지 세션 동안에만 저장합니다(브라우저 간에는 동기화하지 않습니다)
・방문 기록, 쿠키, 위치 정보, X에 표시된 게시물이나 메시지를 광고, 분석, 원격 측정 목적으로 수집하거나 전송하지 않습니다
・테마의 ON/OFF 상태는 브라우저의 동기화 저장소에 저장합니다

■ 동작 조건
・Google Chrome(Edge, Brave 등 Chromium 기반 브라우저에서도 사용할 수 있습니다)
・X의 다크 테마(검정)가 사용 설정되어 있어야 합니다
