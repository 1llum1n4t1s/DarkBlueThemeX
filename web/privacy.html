概要

「帰ってきたDarkBlueテーマ(X)」（以下「本拡張機能」）は、ユーザーのプライバシーを尊重します。テーマ変換の動作で個人情報を収集することはありません。例外は、利用者が自分でお問い合わせフォームを送信したときだけです（「お問い合わせフォーム」の項を参照）。

使用する権限

storage

  • トグル（有効/無効）の状態を保存するために使用します
  • この権限で保存されるデータはブール値（true/false）1つのみです
  • Chrome の同期ストレージを使用し、同一アカウントのデバイス間で設定が同期されます
  • このほかに、権限を必要としない X ページ内の localStorage へ表示用のフラグを保存します（詳細は「データの保存」）

activeTab

  • ポップアップからアクティブなタブの状態を確認するために使用します
  • 現在のタブが X のページかどうかを判定し、テーマの適用状態を表示します

ホスト権限 (x.com, twitter.com)

  • X のページにテーマ変換用の CSS を適用するために必要です
  • これらのサイト以外では一切動作しません

データの収集

本拡張機能は以下のデータを自動的に収集することはありません:

  • 閲覧履歴
  • Cookie
  • 位置情報
  • アクセス解析データ

氏名とメールアドレスは、利用者がお問い合わせフォームに入力して送信したときだけ受け取ります。フォームを使わなければ受け取りません。

外部通信

本拡張機能は、下記のお問い合わせフォームを送信したときを除き、外部サーバーとの通信を行いません。テーマ変換の処理はすべてブラウザ内で完結します。

お問い合わせフォーム

設定画面の「お問い合わせ」ボタンから送信したときだけ、次の情報を Kagayoi Support（https://support.kagayoi.com）へ送信します。ボタンを押さない限り、この通信は発生しません。

  • 入力されたメールアドレス、お名前（任意）、問い合わせ種別、件名、本文
  • 製品ID、拡張機能のバージョン、ロケール

初回はメールで届く6桁の確認コードを Kagayoi Support へ送信して本人確認します。認証後の問い合わせと返信は、利用者本人とサポート担当者が確認できるよう Kagayoi Support に保存します。X（twitter.com）の閲覧内容やテーマ設定は送信しません。

データの保存

本拡張機能が保存するのは、以下の動作設定のみです。いずれも個人を識別しうる情報を含まず、外部には送信されません。

  • chrome.storage.sync: トグルの有効/無効状態（ブール値1つ）。Chrome のアカウント同期機能を通じてデバイス間で同期されます
  • x.com / twitter.com の localStorage: 前回テーマを適用していたかのフラグ（darkbluethemex_was_active）。ページ表示直後の一瞬だけ黒い画面が見える現象（FOUC）を防ぐため、設定の非同期読み込みを待たずに配色を決めるのに使います
  • x.com / twitter.com の localStorage: デバッグログの有効フラグ（dbtx_debug、既定では未設定）。不具合調査時に利用者自身が手動で設定した場合のみ読み取ります

localStorage のデータは X のページ内にのみ保存され、ブラウザの閲覧データ削除でいつでも消去できます。

第三者への提供

本拡張機能は、お問い合わせフォームの内容を除き、データを収集しないため第三者への提供も行いません。お問い合わせの内容は開発者（Kagayoi）のサポート窓口が受け取るもので、広告・解析目的の第三者へ渡すことはありません。

お問い合わせ
