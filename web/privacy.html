概要

「帰ってきたDarkBlueテーマ(X)」（以下「本拡張機能」）は、ユーザーのプライバシーを尊重し、個人情報を一切収集しません。

使用する権限

storage

  • トグル（有効/無効）の状態を保存するために使用します
  • この権限で保存されるデータはブール値（true/false）1つのみです
  • Chrome の同期ストレージを使用し、同一アカウントのデバイス間で設定が同期されます
  • このほかに、権限を必要としない X ページ内の localStorage へ表示用のフラグを保存します（詳細は「データの保存」）

activeTab

  • ポップアップからアクティブなタブの状態を確認するために使用します
  • 現在のタブが X のページかどうかを判定し、テーマの適用状態を表示します

ホスト権限 (x.com, twitter.com)

  • X のページにテーマ変換用の CSS を適用するために必要です
  • これらのサイト以外では一切動作しません

データの収集

本拡張機能は以下のデータを一切収集しません:

  • 個人情報（氏名、メールアドレス等）
  • 閲覧履歴
  • Cookie
  • 位置情報
  • アクセス解析データ

外部通信

本拡張機能は外部サーバーとの通信を一切行いません。すべての処理はブラウザ内で完結します。

データの保存

本拡張機能が保存するのは、以下の動作設定のみです。いずれも個人を識別しうる情報を含まず、外部には送信されません。

  • chrome.storage.sync: トグルの有効/無効状態（ブール値1つ）。Chrome のアカウント同期機能を通じてデバイス間で同期されます
  • x.com / twitter.com の localStorage: 前回テーマを適用していたかのフラグ（darkbluethemex_was_active）。ページ表示直後の一瞬だけ黒い画面が見える現象（FOUC）を防ぐため、設定の非同期読み込みを待たずに配色を決めるのに使います
  • x.com / twitter.com の localStorage: デバッグログの有効フラグ（dbtx_debug、既定では未設定）。不具合調査時に利用者自身が手動で設定した場合のみ読み取ります

localStorage のデータは X のページ内にのみ保存され、ブラウザの閲覧データ削除でいつでも消去できます。

第三者への提供

本拡張機能はデータを収集しないため、第三者への提供も行いません。
